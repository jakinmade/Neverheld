# NEVERHELD

**Not one packet escaped.**

NEVERHELD is a browser-side enforcement and evidence kit. It applies a restrictive Content Security Policy, checks that the browser refuses a self-test request before protected work begins, records per-session observations, derives deterministic control answers, and provides offline proof verification.

This repository is being bootstrapped from the tested seal-kit implementation in EXEVVIA. The initial build is being developed on a dedicated branch; it is not yet a production release.

See `docs/BUILD-STATUS.md` for the extraction boundary, current limitations and release gates.
